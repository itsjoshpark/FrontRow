# Changelog

What changed in each release of Front Row. Generated by [Changie](https://changie.dev) from `.changes/`; edit those files, not this one.

## 3.1.0 - 2026-09-30

- New: File ▸ Move to Trash moves the playing file to the Trash and returns to the welcome window. Hold Option for Delete Immediately…, which deletes it outright after asking

## 3.0.1 - 2026-08-26

- Fixed: Audio Track and Subtitle menus displayed “None” for some files
- Fixed: Tracks with no language tag were listed as “Unknown language” rather than by their name or number
- Fixed: Handling files with multichannel Opus or MP3 audio tracks

## 3.0.0 - 2026-08-22

- New: Front Row offers to convert and play MKV files if possible (using FFmpeg)
- New: Open URL distinguishes between network issue and actually unplayable files
- Changed: Experience Spatial Audio menu item renamed to Play Spatial Audio Sample
- Fixed: Play Spatial Audio Sample started playing without opening a player window
- Updated: App localizations

**Note**: Front Row no longer runs in the app sandbox in order to use FFmpeg. The list of recently opened files will be reset due to this change.

## 2.11.0 - 2026-08-12

- New: Inspector window describing the file you are playing. Open it from the Window menu, or press Command-I
- Fixed: A file exactly one hour long showed its length as 60:00 rather than 1:00:00
- Fixed: Closing the player window left the file loaded, so the playback controls and menu items stayed active with nothing playing
- Updated: App localizations
